# MICP-椰壳纤维协同固化砂土性能分析与预测系统 V1.0 设计说明书

## 1. 软件概述

### 1.1 研究背景

MICP（微生物诱导碳酸钙沉淀）技术可通过生物矿化作用改善砂土结构，椰壳纤维作为天然加筋材料可提升材料韧性与抗裂性。本系统面向 MICP 与椰壳纤维协同固化砂土的科研实验场景，解决试验参数管理分散、数据处理效率低、预测分析依赖人工经验、报告归档标准化不足等问题。

### 1.2 研发目的

- 建立统一的试验参数管理与复用平台
- 基于历史数据实现固化性能预测与灵敏度分析
- 自动完成统计分析、异常值剔除、可视化展示和标准化报告生成
- 为软著申报、科研论文与工程归档提供完整的软件成果载体

### 1.3 适用范围

- MICP-纤维固化砂土试验研究
- 岩土工程材料性能分析
- 教学科研辅助与项目档案管理

## 2. 总体架构

系统采用“前端工作台 + Python 后端服务 + SQLite 数据库 + 可训练模型模块”的分层结构。

### 2.1 架构分层

1. 表现层
   前端使用 HTML/CSS/JavaScript 构建单页工作台，提供参数录入、图表展示、结果预览与报告导出。
2. 服务层
   后端基于 Python 标准库 HTTP 服务实现 REST API，对外提供方案管理、数据集管理、模型训练、性能预测、统计分析、报告生成等接口。
3. 数据层
   使用 SQLite 保存试验方案、历史样本和训练后的模型参数，支持后续扩展为 MySQL/PostgreSQL。
4. 算法层
   提供集成预测模型和 BP 风格神经网络模型的训练与推理接口，并输出参数敏感性分析结果。

### 2.2 模块关系

- 试验参数管理模块负责向数据层写入方案数据，并向预测模块提供输入
- 数据处理模块负责清洗、统计与分析历史样本，并为模型训练提供基础数据
- 性能预测模块负责输出 UCS、干密度、崩解率等核心指标
- 可视化模块基于方案数据与历史样本生成图表
- 报告生成模块整合所有模块输出，生成标准化分析文档

## 3. 功能详细设计

### 3.1 试验参数管理模块

#### 输入

- 砂土干密度
- 椰壳纤维掺量
- 菌液用量
- 菌落 OD 值
- 固化温度
- 固化剂用量
- 固定液用量
- 固化次数

#### 功能

- 单组参数录入与范围校验
- 参数模板保存与复用
- 批量 CSV 导入与参数表导出
- 方案持久化存储

#### 输出

- 试验方案记录
- 参数模板
- 可导出的配置表

### 3.2 固化性能预测模块

#### 输入

- 试验参数方案
- 历史样本数据集
- 已训练模型参数

#### 功能

- 集成模型预测
- BP 风格神经网络预测
- 参数敏感性分析
- 多方案综合评分与推荐

#### 输出

- 无侧限抗压强度
- 固化后干密度
- 浸水崩解率
- 渗透系数
- 内摩擦角
- 黏聚力
- 碳酸钙含量

### 3.3 试验数据处理模块

#### 功能

- 导入历史样本
- 计算均值、标准差、变异系数
- 使用 IQR 规则执行异常值检测
- 进行单因素方差分析，评估纤维掺量对 UCS 的影响显著性

### 3.4 可视化模块

#### 图表类型

- 参数-性能关系曲线
- 样本均值柱状图
- 箱线图
- 参数/指标相关性热力图

### 3.5 报告生成模块

#### 内容组成

- 参数配置摘要
- 性能预测结果
- 敏感性排序
- 数据处理与统计分析结果
- 最优方案推荐

#### 输出形式

- `.doc` 文档导出
- 浏览器打印为 PDF

## 4. 数据库设计

### 4.1 schemes 表

- `scheme_name`：方案名称，主键
- `payload`：方案 JSON 数据

### 4.2 dataset 表

- `sample_id`：样本编号，主键
- `payload`：样本 JSON 数据

### 4.3 model_store 表

- `model_name`：模型名称，主键
- `payload`：训练后模型参数

## 5. 关键流程

### 5.1 性能预测流程

1. 用户录入或选择试验方案
2. 前端调用预测接口
3. 后端读取历史样本与已训练模型
4. 算法模块执行推理并生成敏感性结果
5. 前端展示预测指标和影响因素排序

### 5.2 模型训练流程

1. 用户导入历史样本数据
2. 后端执行集成模型与 BP 风格模型训练
3. 模型参数写入 `model_store`
4. 后续预测接口优先使用已训练模型

### 5.3 报告生成流程

1. 汇总方案、预测、统计分析与推荐结果
2. 生成标准化 HTML 报告
3. 导出为 `.doc` 或打印为 PDF

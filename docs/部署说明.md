# Flask 云部署说明

## 1. 运行环境建议

- Python 3.11 及以上
- Ubuntu 22.04 / CentOS 7+ / Debian 12
- 2 核 4G 内存起步
- Nginx + Gunicorn + Flask

## 2. 部署步骤

### 2.1 上传项目

将 `/Users/xin/Documents/micp` 上传到云服务器，例如：

```bash
scp -r micp user@server:/srv/micp
```

### 2.2 安装依赖

```bash
cd /srv/micp
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install gunicorn
```

### 2.3 启动 Gunicorn

```bash
gunicorn -w 2 -b 0.0.0.0:9000 backend.wsgi:app
```

### 2.4 配置 Nginx

```nginx
server {
    listen 80;
    server_name your-domain-or-ip;

    location / {
        proxy_pass http://127.0.0.1:9000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 3. 生产建议

- 首次部署后立即修改默认管理员账户策略
- 通过 HTTPS 对外暴露服务
- 定期备份 `backend/data/micp.db`
- 后续可将 SQLite 升级为 MySQL/PostgreSQL

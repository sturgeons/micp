# 部署与运行环境说明

## 1. 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | macOS 12+ / Ubuntu 22.04+ / Debian 12 / Windows 10+ |
| Python | 3.10 及以上（开发验证环境 3.14） |
| 第三方库 | Flask、Werkzeug、NumPy、SciPy、scikit-learn、joblib、gunicorn（生产） |
| 数据库 | SQLite 3（Python 内置），单文件 `backend/data/micp.db` |
| 浏览器 | Chrome / Edge / Safari / Firefox 最新版 |
| 硬件 | 单机 2 核 4 GB 即可；训练 48 条样本约 7 s，Morris 分析 (12 轨迹) 约 1 s |

## 2. 本地运行

```bash
cd micp
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 backend/server.py          # http://127.0.0.1:9000
```

首次启动自动建库并写入示范数据。数据库路径可用环境变量 `MICP_DB_PATH` 覆盖。

## 3. 服务器部署

### 3.1 上传与安装

```bash
scp -r micp user@server:/srv/micp
cd /srv/micp
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt gunicorn
python3 backend/bootstrap_admin.py   # 创建 admin / Admin@123456，首次登录后请修改
```

### 3.2 Gunicorn

```bash
gunicorn -w 2 -t 120 -b 127.0.0.1:9000 backend.wsgi:app
```

`-t 120` 为训练接口预留足够超时。建议用 systemd 托管：

```ini
[Unit]
Description=MICP Analysis Service
After=network.target

[Service]
WorkingDirectory=/srv/micp
ExecStart=/srv/micp/.venv/bin/gunicorn -w 2 -t 120 -b 127.0.0.1:9000 backend.wsgi:app
Restart=always

[Install]
WantedBy=multi-user.target
```

### 3.3 Nginx 反向代理

```nginx
server {
    listen 80;
    server_name your-domain-or-ip;
    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:9000;
        proxy_read_timeout 180s;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 4. 验收与维护

- 运行 `python3 scripts/run_acceptance.py` 可在不影响生产库的情况下对全部接口做自动化验收，并生成 `docs/测试报告.md`。
- 定期备份 `backend/data/micp.db`；模型以 base64 存于库内，备份数据库即备份模型。
- 对外服务请通过 HTTPS 暴露，并修改默认管理员密码。
- 若后续样本规模增长到数千条，可将 SQLite 替换为 PostgreSQL，仅需改写 `db.py` 的连接与 SQL 方言，算法包无需改动。

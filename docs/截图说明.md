# MICP 系统运行界面截图说明

本说明配合软件著作权登记材料中的"软件运行界面截图"使用。截图文件统一存放于 `docs/截图资产/`，全部截图均在本机以完整系统模式（Flask 后端 + 浏览器前端，地址 `http://127.0.0.1:9000`）运行时直接抓取，未经任何图像拼接或后期编辑。

截图时的系统状态：

- 登录用户 `researcher`，当前项目「椰壳纤维-MICP 固化砂土试验组 A」；
- 项目内含 4 个试验方案（基准方案 A / 纤维增韧方案 B / 高胶结方案 C / 低成本方案 D）与 48 条历史样本（由 `backend/micp/synthetic.py` 按机理公式生成，含 2 条人工注入的离群样本）；
- 已完成一次「训练并保存模型」，模型版本 v1，三种残差学习器（随机森林 / 梯度提升 / BP 神经网络）均已训练，交叉验证推荐 ensemble（随机森林残差模型）；
- 预测、敏感性、优化、统计、相关性、图表、报告面板均已执行过一次，截图展示的是真实返回结果。

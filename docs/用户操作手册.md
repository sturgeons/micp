# MICP-椰壳纤维协同固化砂土性能分析与预测系统 V1.0 用户操作手册

## 1. 系统简介

本系统面向 MICP 与椰壳纤维协同固化砂土试验研究，提供试验参数管理、固化性能预测、模型训练与评估、参数敏感性分析、多目标配比优化、试验数据统计分析、相关性分析、可视化与报告生成功能。系统通过浏览器访问，页面由上至下分为 10 个编号面板，建议按编号顺序使用。

## 2. 启动与登录

### 2.1 启动服务

```bash
python3 backend/server.py
```

浏览器打开 `http://127.0.0.1:9000`。页面顶部状态栏显示"后端在线"表示服务正常；显示"离线机理模式"表示浏览器无法连接后端，此时仍可使用参数管理、机理预测、偏依赖曲线与图表功能。

### 2.2 顶部快捷按钮

- **载入示范数据**：恢复 4 个示范方案与 48 条示范样本，用于快速体验全部功能。
- **训练并交叉验证**：对当前项目样本训练三种模型并做交叉验证，完成后自动刷新评估面板。
- **生成分析报告**：跳转至报告面板并生成报告预览。

### 2.3 面板 00 账户与项目

1. 在"用户名 / 密码"框输入信息（密码至少 6 位），点击 **注册**，再点击 **登录**。
2. 登录后"项目空间"卡片可用：填写项目名称与说明，点击 **创建项目**。
3. 在"当前项目"下拉框切换项目；方案、样本、模型均按项目隔离存储。
4. 未登录时所有操作作用于公共的"默认项目"。

## 3. 面板 01 试验参数管理

### 3.1 单组方案录入

8 项参数输入框旁标注了单位与合理区间（如"胶结液浓度 (mol/L) 0.1~3"）。填写后输入方案名称，点击：

- **保存方案**：校验通过后写入当前项目，并出现在预测面板的方案下拉框中；校验失败时在下方"校验结果"表列出具体字段与原因。
- **保存模板**：把当前参数保存为可复用模板（存于浏览器本地）。
- **导出参数表**：下载当前项目全部方案的 CSV。

### 3.2 批量导入

点击"导入批量参数 CSV"选择文件。首行为表头，支持英文键名与中文名称混用，例如：

```text
方案名称,干密度,纤维掺量,菌液用量,OD值,温度,胶结液浓度,胶结液用量,固化次数
试验组1,1.6,0.4,120,1.2,30,0.8,90,4
```

导入前系统逐行校验：合格行入库，不合格行在"校验结果"中以橙色高亮并说明原因（如"固化温度 80 超出范围 [20, 40] ℃"）；警告（如固化次数自动取整）以黄色显示。

### 3.3 模板

在"已存模板"下拉框选择模板后点击 **应用模板**，参数自动回填到录入表单。

## 4. 面板 02 固化性能预测

1. **选择方案**：下拉框列出当前项目全部方案。
2. **模型**：
   - 随机森林残差模型 / 梯度提升残差模型 / BP 神经网络残差模型：机理基线 + 数据修正的混合模型，需先训练（样本 ≥ 8 条）；
   - 纯机理模型：仅用 MICP 机理公式，任何时候可用。
3. 点击 **执行预测**。右侧显示：
   - 7 项指标预测卡片；
   - **预测分解表**：每项指标的"机理基线 / 数据修正 / 最终预测"；
   - **机理解释链条**：菌液活性 → 钙源转化 → 孔隙填充 → 纤维桥接 → 机理基线 5 段文字；
   - **参数敏感性（OAT 弹性系数）**：8 项参数的重要度条形图与对 UCS 的弹性值。
4. 若样本不足或模型未训练，预测面板顶部的模型标签会提示"已回退到纯机理模型"。
5. 点击 **方案综合评分**：对项目内全部方案按默认权重打分排序，表格列出得分、UCS、崩解率与成本指数，最优方案高亮。

## 5. 面板 03 模型训练与评估

- **仅评估（不落库）**：对当前样本做交叉验证，不保存模型。
- **训练并保存模型**：交叉验证后全量训练并保存，版本号自动递增。

评估表每行一个学习器，列出折数、验证 R²、验证 RMSE、MAPE、训练 R² 与"机理 R²"（纯机理基线对照）；推荐模型加粗显示，表下方给出过拟合判断。再下方为推荐模型的逐指标评估表。右侧"模型版本历史"列出每次训练的模型、版本、样本数、CV R² 与时间。

样本数与折数关系：8~14 条 3 折，15~59 条 5 折，60 条以上 10 折。

## 6. 面板 04 敏感性深入分析

### 6.1 偏依赖曲线

选择 **扫描参数** 与 **响应指标**，点击 **绘制偏依赖曲线**。曲线表示其余参数固定于当前预测方案时，该参数从区间下限扫到上限引起的指标变化；竖线标记当前方案取值。

### 6.2 Morris 全局敏感性

设置 **轨迹数**（4~60，默认 12，越多越稳定但耗时越长），选择 **查看指标**（"综合"为 7 项指标的汇总），点击 **执行 Morris 分析**。结果表列出各参数的 μ*（主效应强度）与 σ（非线性 / 交互强度）；μ* 大者为主控因素，σ 大者表示与其他参数存在交互或响应非线性。

## 7. 面板 05 多目标配比优化

1. **目标权重**：拖动 7 个滑块设置权重（系统自动归一化），默认 UCS 30、崩解率 15、渗透系数 10、CaCO₃ 10、黏聚力 5、内摩擦角 5、成本 25。
2. **限定在历史样本参数包络内**：勾选（默认）时搜索域不超出历史样本覆盖范围，避免模型外推；取消后在参数字典全区间搜索。
3. 点击 **执行配比优化**。右侧显示评估点数、Top-8 推荐配比表（8 项参数、UCS、崩解率、成本指数、得分）以及 **UCS-成本 Pareto 前沿** 散点图（蓝点为全部候选，橙线为非支配前沿，绿圈标记综合最优）。

## 8. 面板 06 试验数据处理

### 8.1 历史样本

- **导入历史试验数据**：CSV 需包含 8 项参数列与 7 项指标列（表头支持中英文）。不合格行将被列出并跳过。
- **导出历史样本**：下载当前项目样本 CSV。
- **恢复示范样本**：重新写入 48 条内置示范数据。

### 8.2 统计分析

选择 **方差分析因素** 与 **响应指标**，点击 **执行统计分析**，结果包括：

- 异常值检测：被剔除样本的编号、方法（IQR / Grubbs）、阈值与数值；
- 描述统计：7 项指标的均值、标准差、变异系数、四分位数、偏度；
- 单因素方差分析：分组均值、F 值、p 值、η² 与中文结论（p < 0.05 判为显著）；
- UCS-CaCO₃ 回归：线性与幂函数拟合方程及 R²。

## 9. 面板 07 相关性分析

点击 **计算相关矩阵**，显示 8 参数 × 7 指标的 Pearson 相关热力矩阵（红正蓝负，颜色越深相关越强），右侧表格列出显著相关对（|r| 最大且 p < 0.05）。

## 10. 面板 08 可视化与图表

选择 **X 轴参数**、**Y 轴指标** 与 **图表类型**（参数-性能趋势 / 分组柱状图 / 箱线图 / 热力图），点击 **更新图表**。图表基于当前项目的历史样本绘制。

## 11. 面板 09 标准化报告

1. 点击 **刷新预览**：服务端汇总当前预测、统计分析、模型评估与优化结果，生成含 SVG 图表的 HTML 报告并在页面内嵌显示。
2. 点击 **导出报告**：下载 `.doc` 文件，可直接用 Word 打开；也可在预览中使用浏览器打印保存为 PDF。

报告章节：方案参数、机理解释链条、性能预测与分解、参数敏感性、模型评估、统计分析、配比优化建议、结论。

## 12. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 预测结果标注"已回退到纯机理模型" | 当前项目样本不足 8 条或尚未训练；导入样本后点击"训练并交叉验证" |
| 导入 CSV 后提示"未识别的表头" | 表头拼写与字典不符；参考 3.2 节表头示例或 `GET /api/dictionary` 中的别名 |
| 方差分析提示"样本或分组数量不足" | 所选因素取值过于集中或样本太少；更换因素或补充样本 |
| 配比优化结果 UCS 明显高于历史样本 | 取消了"限定在历史样本包络内"导致模型外推；建议重新勾选 |
| 页面显示"离线机理模式" | 后端未启动或端口被占用；启动 `backend/server.py` 后刷新页面 |
| 登录后看不到项目 | 需先点击"创建项目"；默认项目对所有用户开放 |

# MICP 软件基础信息与功能说明

## 软件基础信息

- 软件全称：MICP-椰壳纤维协同固化砂土性能分析与预测系统
- 软件简称：MICP 固化砂土分析预测系统
- 版本号：V1.0
- 软件类型：工程试验数据分析与性能预测软件
- 运行方式：浏览器访问的前后端一体化应用，支持本地离线前端工作台模式
- 适用对象：岩土工程、土体固化、MICP 试验研究和工程数据归档相关人员
- 材料整理日期：2026-06-23

## 软件功能说明

本软件面向椰壳纤维协同 MICP 固化砂土试验场景，围绕试验参数录入、历史样本管理、模型训练、性能预测、统计分析、结果可视化和报告生成构建完整工作流程。系统支持用户登录和项目空间管理，可将不同课题、试验批次或工程项目的数据进行隔离保存。

### 1. 用户与项目管理

系统提供用户注册、登录、退出、项目创建、项目切换和项目刷新功能。登录后用户可创建独立项目空间，并在项目维度下管理试验方案、历史样本和模型结果，便于多人协作和数据归档。

### 2. 试验参数管理

系统支持录入砂土干密度、椰壳纤维掺量、菌液用量、菌落 OD 值、固化温度、固化剂用量、固定液用量和固化次数等参数。用户可保存单组试验方案、保存常用参数模板、应用已有模板，并可通过 CSV 文件批量导入参数方案。

### 3. 历史样本管理

系统支持导入历史试验样本数据，并以表格形式展示样本编号、无侧限抗压强度、固化后干密度、碳酸钙含量等关键指标。历史样本可用于模型训练、预测校准、统计分析和报告生成。

### 4. 模型训练与性能预测

系统可基于历史样本训练集成模型和 BP 风格模型，并对选定参数方案输出固化性能预测结果。预测指标包括无侧限抗压强度、固化后干密度、浸水崩解率、渗透系数、内摩擦角、黏聚力和碳酸钙含量。

### 5. 参数敏感性与方案优选

系统可分析各试验参数对预测结果的影响权重，生成参数敏感性排序。用户还可对多组方案进行综合评分和排序，用于辅助确定优先验证或推荐采用的固化参数组合。

### 6. 统计分析

系统可对历史样本执行描述统计、异常值检测、变异系数分析和单因素方差分析，帮助用户从试验数据中识别离散程度、异常样本和主要差异来源。

### 7. 可视化分析

系统支持参数-性能关系曲线、对比柱状图、箱线图和热力图等可视化形式。用户可选择不同 X 轴参数、Y 轴指标和图表类型，直观观察参数变化对固化性能的影响。

### 8. 报告生成与导出

系统可自动汇总参数配置、预测结果、敏感性分析、统计分析和结论建议，生成标准化报告预览，并支持导出为可归档文档。该功能用于科研记录、工程报告和软著材料展示。

## 软件技术特点

- 采用 Flask 后端服务统一托管页面和 API。
- 使用 SQLite 存储用户、项目、试验方案、样本数据和模型信息。
- 集成 scikit-learn 模型能力，支持集成模型和 BP 风格模型训练。
- 前端提供离线可运行工作台，便于无服务器环境下演示核心功能。
- 运行截图与说明文档已按软著材料顺序整理，便于登记材料归档。

## 2. 开发目的与解决的问题

MICP（微生物诱导碳酸钙沉淀）与纤维协同固化砂土试验涉及菌液活性、钙源供给、灌注工艺、孔隙结构与纤维掺量等多因素耦合，单次试验周期 7~28 天。现有通用数据分析工具无法利用领域机理知识，在数十条样本的小数据条件下直接做机器学习往往得到无物理意义的外推结果。本系统的创新点在于：

1. **机理-数据混合建模**：建立包含菌液饱和动力学、温度活性、逐轮钙源转化与孔隙堵塞、纤维桥接、Kozeny-Carman 渗透等环节的 MICP 机理模型作为预测基线，机器学习只拟合机理模型未覆盖的残差；小样本下自动退化为纯机理预测，任何一次预测都能拆分为"机理解释部分 + 数据修正部分"。
2. **机理特征工程**：把 8 项试验参数转换为有效菌量、钙源转化效率、孔隙填充率、纤维桥接因子等 8 项具有物理意义的中间量，既作为模型输入，也作为报告中的解释依据。
3. **三层敏感性分析**：局部 OAT 弹性系数、单参数偏依赖曲线、Morris 全局基本效应（μ*/σ）组合使用，区分主效应与交互效应。
4. **不外推的多目标配比优化**：拉丁超立方采样 + 高斯局部细化，7 项性能指标与成本指数加权，默认限制在历史样本参数包络内，输出 UCS-成本 Pareto 前沿。
5. **面向试验数据特点的统计检验**：IQR + Grubbs 迭代异常值检测、按水平或分位数自动分组的单因素方差分析（含 p 值与 η²）、UCS-CaCO₃ 线性与幂函数回归、参数-指标 Pearson 相关矩阵。
6. **数据可信性保障**：三层校验（结构、区间、物理一致性）、中英文表头自动映射、模型版本历史、全部随机过程固定种子可复现。

## 3. 功能说明

### 3.1 账户与项目管理

用户注册、登录、退出；创建项目、切换项目；方案、样本、模型按项目隔离，未登录用户使用公共默认项目。

### 3.2 试验参数管理

8 项参数单组录入（带单位与合理区间提示）、方案模板保存与回填、CSV 批量导入（中英文表头）、导入前逐行校验并高亮错误与警告、参数表导出。

### 3.3 固化性能预测

4 种模型（随机森林残差 / 梯度提升残差 / BP 神经网络残差 / 纯机理）对 7 项性能指标预测；预测分解表；机理解释链条；OAT 参数敏感性条形图；多方案综合评分排序。

### 3.4 模型训练与评估

自适应 K 折交叉验证（3 / 5 / 10 折），逐指标 R²、RMSE、MAE、MAPE，纯机理基线对照，过拟合差距判断，推荐模型自动选择，模型版本历史记录。

### 3.5 敏感性深入分析

偏依赖曲线（任意参数 × 任意指标）；Morris 全局敏感性（可调轨迹数，输出 μ* 与 σ，按指标或综合查看）。

### 3.6 多目标配比优化

7 个目标权重滑块，是否限定样本包络开关；输出 Top-8 推荐配比、评估点数、UCS-成本 Pareto 前沿图。

### 3.7 试验数据处理

历史样本导入 / 导出 / 恢复示范；异常值检测明细；7 项指标描述统计；单因素方差分析（因素与响应可选）；UCS-CaCO₃ 回归。

### 3.8 相关性分析

8 参数 × 7 指标 Pearson 相关热力矩阵与显著相关对列表。

### 3.9 可视化

参数-性能趋势散点、分组柱状图、箱线图、热力图，X/Y 轴可选。

### 3.10 标准化报告

服务端生成含 SVG 图表的 8 章 HTML 报告，页面内预览，导出 Word（.doc）或打印 PDF。

### 3.11 离线机理模式

后端不可达时前端自动切换为内置 JavaScript 机理模型，参数管理、机理预测、OAT 敏感性、偏依赖曲线与图表仍可使用。

## 4. 技术特点

- 后端 Flask + SQLite，算法包 `backend/micp` 与 Web 层解耦，可独立调用与单元测试；
- 机理模型全部系数集中于 `MechanismConstants` 数据类，便于按实际试验标定；
- 模型以 joblib 序列化后 base64 存入数据库，备份数据库即备份模型；
- 前端无第三方图表库依赖，Canvas 2D 自绘 7 类图表；
- 自动化验收脚本 `scripts/run_acceptance.py` 覆盖全部 22 个接口、31 个用例，生成含真实返回值的测试报告。

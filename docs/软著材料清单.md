## 2. 源程序鉴别材料收录范围

仅收录具有独创性的业务代码，不含 README、依赖清单、样式表与第三方库：

| 文件 | 内容 |
| --- | --- |
| backend/micp/schemas.py | 数据字典与表头别名 |
| backend/micp/mechanism.py | MICP 机理模型 |
| backend/micp/models.py | 机理-残差混合模型 |
| backend/micp/evaluation.py | 自适应交叉验证 |
| backend/micp/sensitivity.py | OAT / Morris / 偏依赖 |
| backend/micp/optimizer.py | 多目标配比优化 |
| backend/micp/statistics.py | 异常值 / ANOVA / 相关 / 回归 |
| backend/micp/validators.py | 校验与 CSV 解析 |
| backend/micp/synthetic.py | 示范数据生成 |
| backend/micp/report.py | SVG 报告 |
| backend/micp/__init__.py | 算法门面 |
| backend/db.py | SQLite 数据访问 |
| backend/server.py | Flask 接口层 |
| backend/ml.py、wsgi.py、bootstrap_admin.py | 兼容入口、WSGI、管理员初始化 |
| backend/static/app.js | 前端逻辑与 JS 机理模型 |
| backend/templates/index.html | 页面结构 |

## 3. 生成方式

```bash
python3 scripts/run_acceptance.py            # 生成 docs/测试报告.md
python3 scripts/build_word_docs.py           # 生成 docs/word/*.docx
python3 scripts/build_registration_form.py   # 生成软著信息登记表
```

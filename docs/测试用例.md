# MICP 系统测试用例

## 1. 功能测试

| 用例编号 | 模块 | 测试目标 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|---|
| TC-001 | 用户注册 | 验证用户可成功注册 | 后端已启动 | 输入新用户名和密码，点击注册 | 返回注册成功信息 |
| TC-002 | 用户登录 | 验证用户可成功登录 | 已存在测试用户 | 输入用户名和密码，点击登录 | 返回 Token，页面显示登录状态 |
| TC-003 | 项目创建 | 验证项目空间可创建 | 用户已登录 | 输入项目名和说明，点击创建项目 | 项目出现在项目列表中 |
| TC-004 | 参数管理 | 验证单组参数保存 | 页面已打开 | 输入合法参数并点击保存方案 | 方案写入表格和数据库 |
| TC-005 | 参数校验 | 验证非法参数拦截 | 页面已打开 | 将纤维掺量设为 1.5% 并保存 | 前端提示超出范围 |
| TC-006 | 批量导入 | 验证参数 CSV 导入 | 准备合法 CSV | 选择 CSV 文件导入 | 成功导入多组方案 |
| TC-007 | 数据集导入 | 验证历史样本导入 | 准备合法 CSV | 选择历史样本 CSV 导入 | 数据表与数据库更新 |
| TC-008 | 模型训练 | 验证 scikit-learn 模型训练 | 项目中已有样本 | 点击训练模型 | 返回 ensemble、bp 训练成功 |
| TC-009 | 性能预测 | 验证预测接口可返回结果 | 已训练模型 | 选择方案并点击执行预测 | 返回 7 项性能指标 |
| TC-010 | 统计分析 | 验证统计分析输出 | 已导入样本 | 点击执行统计分析 | 返回均值、标准差、CV、ANOVA |
| TC-011 | 图表展示 | 验证图表渲染正常 | 已存在样本 | 切换图表类型并更新图表 | Canvas 正常展示结果 |
| TC-012 | 报告生成 | 验证报告导出 | 已执行预测和分析 | 点击生成分析报告 | 输出 doc 下载并支持打印 PDF |

## 2. 接口测试

| 用例编号 | 接口 | 请求方法 | 测试点 | 预期 |
|---|---|---|---|---|
| API-001 | `/api/health` | GET | 服务健康检查 | 返回 `ok=true` |
| API-002 | `/api/auth/register` | POST | 注册新用户 | 返回用户对象 |
| API-003 | `/api/auth/login` | POST | 登录认证 | 返回 token |
| API-004 | `/api/projects` | GET | 获取项目列表 | 返回当前用户可访问项目 |
| API-005 | `/api/train` | POST | 训练模型 | 返回已训练模型名及指标 |
| API-006 | `/api/predict` | POST | 推理预测 | 返回 metrics 与 sensitivity |
| API-007 | `/api/analyze` | POST | 统计分析 | 返回 metricStats 与 anova |
| API-008 | `/api/report` | POST | 报告生成 | 返回 html 内容 |

## 3. 性能与稳定性测试建议

- 连续导入 1000 条历史样本，验证训练接口是否正常返回
- 连续切换多个项目，验证项目间数据不会串扰
- 使用不同浏览器访问，验证前端兼容性
- 在云服务器环境验证 Flask 启动、Gunicorn 托管和静态资源访问

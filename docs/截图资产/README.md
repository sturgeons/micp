## 重新截图

1. 启动服务：`.venv/bin/python backend/server.py`；
2. 浏览器打开 `http://127.0.0.1:9000`，注册 / 登录后点击「载入示范数据」「训练并交叉验证」；
3. 依次执行各面板操作（参见 `../用户操作手册.md`），滚动到对应面板后截取浏览器视口；
4. 按上述文件名覆盖保存，并同步更新 `../截图说明.md` 中的说明文字。
